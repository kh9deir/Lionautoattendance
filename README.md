# Lion Auto Attendance v1 (prototype)

واجهة عربية RTL متجاوبة لإدارة الحضور والانصراف متعددة المواقع والورديات وأنظمة الأجر المختلفة.

## التشغيل
- افتح `index.html` مباشرة في متصفح حديث على الكمبيوتر أو الموبايل.
- لا تحتاج إلى تثبيت حزم أو إعداد خادم لتجربة الواجهة.
- التعديلات تُحفظ في `localStorage` داخل نفس المتصفح والجهاز فقط.

## ما الذي تتضمنه النسخة
- لوحة متابعة لشهر سبتمبر 2026.
- قائمة موظفين أولية بأسماء وأرقام ظاهرة في تقرير ZKTeco.
- سجل أحداث تجريبي يوضح حالات التكرار المحتمل ونوع البصمة الناقص ومراجعة التوقيت.
- تعديل الموظفين والمواقع ونظام الأجر والوردية.
- إضافة/تعديل أحداث يدويًا، مع طلب سبب التعديل.
- تصدير CSV لسجل المراجعة ومسودة الرواتب غير المعتمدة.
- تعطيل اعتماد الرواتب فعليًا حتى استكمال إعداد الأجور والورديات ومراجعة كل البصمات.

## قيود مهمة
- هذه **واجهة نموذج أولي** وليست نظام إنتاج آمنًا متعدد المستخدمين.
- رفع PDF في هذه النسخة يسجل اختيار الملف في الواجهة فقط؛ لا يوجد بعد مستخرج PDF آلي موثوق أو مطابقة تلقائية لكل صفحة.
- أحداث المثال في سجل المراجعة توضيحية لحالات يجب مراجعتها، وليست استيرادًا كاملًا أو كشفًا معتمدًا من التقرير.
- لا توجد مصادقة أو صلاحيات خادم أو قاعدة بيانات مركزية أو سجل تدقيق مقاوم للتعديل.
- لا تعتمد أي رواتب بناءً على هذه النسخة.

## المرحلة التالية قبل التشغيل الحقيقي
1. إضافة مستخرج PDF/OCR مع حفظ كل حدث خام ومصدر الصفحة والثقة.
2. شاشة مطابقة واعتماد بشرية للتكرارات والبصمات الناقصة والموظف/الموقع/الوردية.
3. قاعدة بيانات مركزية ومصادقة وصلاحيات وسجل تدقيق.
4. محرك رواتب بقواعد معلنة واختبارات وحدات قبل التصدير النهائي.
