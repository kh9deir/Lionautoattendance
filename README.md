# نظام الحضور والانصراف — Lion Auto v1

واجهة عربية لقراءة تقرير بصمة PDF والعمل على بياناته مؤقتًا داخل المتصفح.

## ماذا يحدث بعد رفع الملف؟

1. اختاري ملف PDF. يقبل النظام ملفات حتى 20 ميجابايت.
2. يستخرج أسماء الموظفين وأرقام البصمة والتاريخ والوقت ونوع الحركة الواضح في التقرير.
3. يضيف الموظفين إلى صفحة **الموظفون** والحركات إلى **سجلات البصمة**.
4. راجعي كل الحركات. التكرارات المحتملة وأنواع البصمة غير الواضحة تظل معلّمة للمراجعة، ولا تُحذف أو تُعتمد تلقائيًا.
5. أدخلي الموقع والوردية ووقت بدايتها ونهايتها ونظام الأجر يدويًا من صفحة **الموظفون** عند الحاجة. بعد إدخال بداية الوردية، يعرض النظام مؤشر تأخير محتمل للحضور الواضح.

لا يفترض التطبيق شهرًا محددًا؛ يعمل على التاريخ الموجود في الملف المختار. عند رفع ملف آخر تُستبدل بيانات الملف السابق. زر **مسح الملف وسجلاته** يزيل بيانات الجلسة الحالية.

## التشغيل على Windows

1. فكّي ضغط ملف ZIP.
2. افتحي مجلد `attendance-app-v1`.
3. اضغطي مرتين على `تشغيل-النظام.bat`.
4. اختاري ملف PDF من صفحة سجلات البصمة.
5. لإيقاف الخادم المحلي، أغلقي نافذة **Lion Auto local server**.

يحتاج التشغيل إلى Node.js أو Python. في أول قراءة يحتاج المتصفح إلى اتصال بالإنترنت لتحميل PDF.js 6.3.289 من jsDelivr. ملف البصمة نفسه يُقرأ داخل المتصفح ولا يُرسل إلى الخادم.

## الخصوصية

- لا توجد قاعدة بيانات أو كتابة إلى `localStorage`.
- بيانات الموظفين والحركات والإعدادات تبقى في ذاكرة صفحة المتصفح الحالية فقط، وتختفي عند تحديث الصفحة أو إغلاقها.
- اختيار ملف جديد يستبدل بيانات الملف السابق في الجلسة.
- الخادم المحلي يستمع على `127.0.0.1` ويخدم صفحة التطبيق فقط.

## الحدود الحالية

- استخراج الجداول النصية ذات الأعمدة المدعومة في تقرير البصمة؛ ملفات PDF المصورة أو الممسوحة ضوئيًا تحتاج OCR غير متوفر هنا.
- الموقع والوردية والأجر ليست في ملف البصمة المستخدم؛ لا يخمنها التطبيق.
- مؤشر التأخير يحتاج إدخال وقت بداية الوردية وسماح التأخير. الوردية الليلية تظل للمراجعة اليدوية.
- لا يحسب التطبيق الغياب من غياب بصمة وحده، لأن أيام العمل والراحة غير معرفة.
- لا يوجد حساب رواتب مكتمل أو اعتماد نهائي. تصدير الرواتب مسودة فقط.
- جميع سجلات الحضور المستوردة تحتاج مراجعة بشرية قبل أي اعتماد أو حساب.

## رفع المشروع إلى GitHub

ارفعي الملفات الأربعة إلى جذر المستودع: `index.html` و`README.md` و`server.cjs` و`تشغيل-النظام.bat`. يمكن استخدام GitHub Pages لفتح التطبيق كصفحة ثابتة. لا ترفعي ملف بصمة الموظفين إلى GitHub.
