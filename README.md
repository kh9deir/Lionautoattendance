# نظام الحضور والانصراف — Lion Auto v1

واجهة عربية لمعاينة ملف الحضور PDF صفحةً بصفحة. تفتح مباشرةً على اختيار الملف، ولا تربط التقرير بشهر ثابت.

## التشغيل على Windows

1. فكّي ضغط الملف.
2. افتحي مجلد `attendance-app-v1`.
3. اضغطي مرتين على `تشغيل-النظام.bat`.
4. من صفحة التطبيق اضغطي **اختيار ملف PDF** وحددي التقرير.
5. لإيقاف الخادم المحلي، أغلقي نافذة **Lion Auto local server**.

يحتاج التشغيل إلى Node.js أو Python مثبتًا على الجهاز. لا تحتاجين إلى تثبيت حزم للمشروع. عند أول معاينة يحتاج المتصفح إلى الإنترنت لتحميل PDF.js 6.3.289 من jsDelivr. الملف نفسه يُقرأ داخل المتصفح.

## الخصوصية

- يعمل التطبيق على ملف PDF الذي تختارينه في الجلسة الحالية فقط؛ لا يقارن شهره بفترة محددة.
- لا يحفظ التطبيق الملف أو البيانات في قاعدة بيانات أو في التخزين المحلي. تختفي المعاينة وأي تعديلات يدوية عند تحديث الصفحة أو إغلاقها.
- عند التشغيل، يحذف التطبيق مفتاح التخزين القديم الخاص بالنموذج السابق فقط.
- الخادم المحلي يخدم صفحة التطبيق فقط ويستمع على جهازك (`127.0.0.1`). لا يرفع ملفات PDF.
- حد الملف 20 ميجابايت، مع التحقق من الامتداد ونوع الملف وترويسة PDF.

## ما الذي تعرضه النسخة

- اسم الملف، حالة التحميل والقراءة، عدد الصفحات، ونص كل صفحة.
- أسطر تحتوي نمط تاريخ ووقت محتمل للمراجعة. هذا عدّ نصي أولي وليس عدد بصمات مؤكّدًا.
- واجهة تدعم عدة مواقع، ووردية ونظام أجر لكل موظف. الإعدادات يدوية ومؤقتة لهذه الجلسة.
- لا توجد أسماء موظفين أو سجلات تجريبية مسبقة. لا تتحول المعاينة تلقائيًا إلى أحداث حضور.

## الحدود الحالية

- لا يوجد OCR للملفات الممسوحة ضوئيًا.
- لا توجد مطابقة تلقائية للموظفين أو المواقع أو الورديات، ولا اعتماد للتكرارات والبصمات الناقصة.
- لا يوجد حساب رواتب مكتمل أو معتمد. راجعي السطور مع أصل التقرير قبل أي قرار.
- هذه نسخة أولية وليست نظام إنتاج متعدد المستخدمين.
