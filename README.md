# نظام الحضور والانصراف — Lion Auto

نسخة عربية باتجاه RTL لإدارة موظفي عدة مواقع ومواعيد عمل مختلفة ومراجعة سجل البصمة المستخرج من PDF.

## ماذا يحدث عند رفع PDF؟

1. من **سجل الحضور** أو الصفحة الرئيسية اختر **استيراد PDF**.
2. يقبل التطبيق ملفات PDF حتى 20 ميجابايت ويتحقق من نوعها وبداية محتواها. يظهر اسم الملف وحالة القراءة، ثم يعرض النص المستخرج من كل صفحة وحركات البصمة التي قرأها.
3. راجع التاريخ والموظف والوقت ونوع الحركة لكل بصمة. الحركات المكررة أو المتقاربة خلال دقيقة تبدأ غير محددة، والوقت الذي يحتمل صباحًا أو مساءً يحتاج اختيارًا يدويًا. لا يجمع التطبيق البصمات ولا يحوّل أول وآخر حركة تلقائيًا إلى حضور وانصراف.
4. يمكنك وضع اقتراح للحضور والانصراف في الأيام التي لها بصمتان فقط؛ الاقتراح لا يُحفظ قبل مراجعتك وتحديد مربع التأكيد.
5. عند تأكيد الملف، يستبدل سجل الحركات الحالي (بما فيه التعديلات اليدوية) بحركات هذا الملف وحده لتجنب خلط الفترات. يحتفظ التطبيق ببيانات الموظفين والمواقع والورديات وأنظمة الأجر والسلف المحفوظة محليًا.

## الحفظ والخصوصية

- بيانات الموظفين والحركات والإعدادات تحفظ في مساحة المتصفح المحلية على هذا الكمبيوتر. تبقى بعد إغلاق الصفحة وفتحها مجددًا على العنوان نفسه.
- ملف PDF يُقرأ داخل المتصفح ولا يُرسل إلى الخادم المحلي. لا تُحفظ حركاته إلا بعد تأكيد مراجعتها.
- مسح بيانات الموقع من إعدادات المتصفح أو تغيير عنوان التشغيل/الموقع يمسح الوصول إلى البيانات المحفوظة على ذلك العنوان. استخدم **تنزيل نسخة احتياطية** واحفظ ملف JSON في مكان آمن، ثم **استعادة نسخة JSON** عند الحاجة.
- لا ترفع ملف البصمة إلى مستودع GitHub؛ ارفع ملفات البرنامج فقط.

## التشغيل على Windows

1. فك ضغط ملف ZIP إلى مجلد على جهازك.
2. افتح المجلد واضغط مرتين على `تشغيل-النظام.bat`.
3. سيفتح التطبيق في المتصفح على `http://127.0.0.1:8000/`. أغلق نافذة الخادم لإيقافه.
4. يحتاج التشغيل إلى Node.js أو Python. ملف التشغيل يختار Node.js أولًا ثم Python إن كان متاحًا.

## رفع المشروع إلى GitHub

ارفع `index.html` و`app.js` و`README.md` إلى جذر المستودع. إذا شغّلت التطبيق من GitHub Pages، ستُحفظ البيانات محليًا في المتصفح نفسه لهذا الموقع، منفصلة عن بيانات العنوان المحلي `127.0.0.1`. لن تنتقل البيانات تلقائيًا بين الجهازين أو المتصفحات؛ استخدم النسخة الاحتياطية لنقلها.

## نطاق الحساب وحدوده

- يدعم التطبيق الموقع والوردية وأيام العمل ونموذج الأجر الشهري أو اليومي أو بالساعة لكل موظف.
- خصومات الغياب لا تُعتمد تلقائيًا؛ سجّل الغياب يدويًا بعد المراجعة. البصمات الناقصة أو الإضافية أو المتكررة تبقى للمراجعة.
- الرواتب والتصدير مسودات وليست نظام رواتب مكتملًا أو اعتمادًا نهائيًا. قواعد الخصم العامة قابلة للتعديل وتحتاج مطابقة سياسة الشركة.
- يمكن استخراج النص من PDF النصي. ملف صورة ممسوحة ضوئيًا يحتاج OCR، وهو غير متوفر في هذه النسخة.
- كل عمليات استخراج PDF تتم على جهازك، ولا توجد قاعدة بيانات سحابية أو تسجيل دخول.
